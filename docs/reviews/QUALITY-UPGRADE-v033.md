## 12점 목표를 평가하는 방법

기본 품질은 10점 척도로 기록한다. 기능은 재현 가능한 실패·경고로 평가하고, 조형·이야기·재미 설계는 검토자의 판단이라고 명시한다. 최대 2점의 초과 목표는 기본 문제가 해결된 뒤 별도로 확인한다. 학생 평가 없이 ‘아이들이 재미있어한다’는 초과점을 부여하지 않는다.

| 사용자 관심 영역 | 수정 전 진단 /10 | 기본 품질 기준 | 11~12점 초과 목표 |
|---|---:|---|---|
| 재미·공정한 도전 | 7 | 입력 판정 일관성, 가능한 보상, 읽기·교정 존중, 재도전 선택 | 여러 언어·모드에서 일관된 반응 + 실제 학생의 자발적 재도전 확인 |

## 구현 결과

### 판정과 보상의 공정성

- 입력 중 이미 센 오류를 Enter에서 다시 세지 않는다. 한글 `친구와 문을 열자.`의 수정 사례는 제출 전후 정확도95.65%, 영어 문장부호 수정 사례는96.43%로 동일하다. 다른 새 오류·누락·추가 글자는 별도로 센다.
- 6문장 편지와3문장 전보도 정확도90% 이상으로 완주하면 정확 입력 인장을 얻는다. 목표별 하루1회 지급과 재도전 중복 방지는 유지한다.
- 전보의 최대 완성 수가3이므로 불가능했던12콤보 별 목표를 실제 가능한3콤보로 맞췄다. 별3개는 완료·정확도95%와 시간 또는 콤보 조건을 함께 확인한다.
- 오류 원문을1회 고치고 다른 예시2개에 적용하면 해당 추천을 완료 처리한다. 새로운 오류가 생기면 다시 추천하고, 과거 누적 학습 기록은 보존한다.
- 코인 임계값을 이번 보상으로 넘었을 때 같은 결과에서 배지를 지급한다. 점수 설명은 실제 모드별 보너스·PERFECT의 삭제 키 조건을 반영한다.

### 다시 시작할 이유와 세계관

- 새 조합의 사막·열차에는 언어별27문장, 총54문장을 추가했다. 지역별3개 이야기 중 하나를 골라 순서를 유지하고 같은 페이지에서 직전 이야기 세트를 피한다. 문장 단위 영구 미중복을 약속하지 않는다.
- 짧은 낱말은 같은 지역·난도·길이·학습 태그 묶음 안에서 순서를 바꾼다. 학습 목표가 달라지는 무분별한 지역 간 섞기를 제거했다.
- 홈→지도→소개→완주 결과를 다섯 빛의 회복으로 연결했다. 실제 저장의 지역 완료 목록을 사용해 빛을 계산하고, 새 화폐나 별도 진도를 추가하지 않았다.
- 모험 플러스는 지역 카드에서 다음 목표를 읽고 소개와 연습을 거쳐 시작한다. 카드마다 원래 지역의 행동·이야기·다음 별 조건을 설명한다.

### 화면 균형과 안정성

- 홈은 시작/이어하기·연습·모험 플러스를 우선 배치하고, 추가 메뉴는 펼쳐보기로 정리했다.
- 소개는 지역 미션·되찾을 빛을 먼저 보여준다. 학습 설명·난도·별 조건은 펼쳐보기 안에 있으며 캐릭터·펫·몬스터·말풍선이 설명 패널과 겹치지 않게 배치했다.
- 결과는 정확도·완성 수·점수와 되찾은 빛을 먼저 보여주고, 상세 학습 기록·보상·점수 계산은 펼쳐서 확인한다.
- 영어 말풍선은 전체 문장을 번역한 뒤 글자 애니메이션을 시작한다. 영어 화면에서 한글이 잠깐 나타나던 현상을 제거했다. 동작 줄이기 설정에서는 문장을 바로 표시한다.
- 작은 지도의 빛 패널은 기호·수량 중심으로 줄이고 유물 이름은 접근성 이름·툴팁 및 지역 소개/결과에 유지한다.
- 지도 핀은 회전·움직임을 포함해 화면 상단 안에 머무르게 했다. 실제 지역 좌표와 캐릭터 이동은 유지한다. 전체 회복 제목도 단순 완료 목록 길이가 아니라 실제 다섯 지역의 완료 여부를 사용한다.

## 검증 범위와 재실행 원칙

자동 입력은 실제 화면의 입력란으로 목표를 완성했음을 뜻한다. 실제 어린이의 타자 속도·학습 전이·흥미를 대신하지 않는다. 사용자 브라우저의 저장을 지우지 않고 격리한 Chrome 프로필에서 검사했다.

서로 다른 검사 단위(문장, 사례, 자산, 화면)를 하나의 총 검사 수로 합산하지 않는다. 바뀐 코드의 검사와 이전 버전에서 유지한 근거를 구분하며, 전체 과거 검사 수를 새 버전의 결과로 옮겨 쓰지 않는다.

최종 검수 중 자동 검사의 이전 홈 메뉴 접근과 숨은 결과 컨테이너 판별을 현재 UI에 맞게 고쳤다. 이는 앱 동작 수정과 구분한다. 디자인의1920px 영어 소개→전투 진입이 한 번60초 대기에서 끝난 기록은 보존했다. 같은 흐름을 단독 재실행했을 때 콘솔·페이지·요청 오류 없이 통과했으며, 최초 현상의 원인은 확정하지 않았다.
