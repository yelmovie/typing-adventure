# 인증서·모험 도감 넘침 수정 및 로컬 실행 복구

2026-09-11. v0.3.3의 기존 작업을 보존하고 두 세부 창의 높이·스크롤과 자료 실패 안내만 수정했다. 전체 게임을 새로 채점한 보고서가 아니다.

## 확인한 원인

- 인증서는 높이가 제한된 모달 안에 긴 `.cert`와 확인 버튼을 그대로 배치했다. 인증서의 내용 높이는 줄지 않고 `overflow: visible`이어서 모달 테두리와 화면 아래로 넘쳤다. 915×412 초기 재현에서 인증서 본문 하단은727px, 확인 버튼 하단은787px까지 내려갔다. 근거: `tmp/detail-dialogs-before/`.
- 도감에는 이미 별도 목록 스크롤 처리가 있는 소스가 있었다. 기존 변경을 보존하면서 제목·닫기·탭과 카드 내부 내용까지 검사하고 두 창에 같은 높이 제한 구조를 적용했다. 기존 소스에서 도감 목록 전체가 넘쳤다고 단정하지 않는다.
- 사용자가 올린 오류 문구는 `BootScene`이 자료 하나라도 받지 못하면 인터넷 상태와 무관하게 표시하던 공통 문구였다. 검사 당시127.0.0.1:4176과5180 연결이 거부됐으며, 로컬 미리보기 서버를 다시 실행한 후 홈·배경·캐릭터 자료가HTTP200으로 응답하고 실제 홈이 열렸다. 인터넷 회선 전체를 검사했다는 뜻은 아니다.

## 변경

1. 두 창을 고정 헤더·내부 스크롤 영역·필요한 하단 버튼으로 나눴다. 제목과 닫기 버튼은 실제 레이아웃 공간을 차지하므로 긴 제목이 내용을 덮지 않는다.
2. 인증서의 긴 성장 기록·일일 기록·자기평가를 내부에서 스크롤한다. 확인 버튼은 스크롤과 별개로 항상 보인다. 마지막 입력란과 저장 동작을 유지한다.
3. 도감은 탭을 고정하고 카드 목록만 스크롤한다. 카드 안의 설명·친구 선택 버튼은 카드 경계 안에 유지하고 긴 영어 탭 문구는 줄바꿈한다.
4. 작은 화면에서도 닫기 버튼은48px 이상, 닫기 표시와 인증서 칭호 글자는 읽을 수 있는 크기를 사용한다. 스크롤바를 명시해 아래 내용이 있음을 보여준다.
5. 자료 실패만으로 인터넷 단절을 단정하지 않는다. 로컬 주소에서는 서버 실행 확인을 안내하고, 일반 주소에서는 자료 불러오기 실패와 재시도를 안내한다. 한영 안내와 다시 받기 동작을 확인했다.

## 현재 미리보기

- 주소: `http://127.0.0.1:4176/?v=0.3.3-dialog-fix`
- 출력: **`dist-preview-20260911/`**, 앱 버전0.3.3
- manifest: **`de6cfafa42a6871e`**,427자산·52,407,580B
- 앱 파일: `index-DP-IdI8_.js`, `index-UWIqdSIR.css`
- 재실행: 프로젝트 폴더에서 `npm run preview -- --outDir dist-preview-20260911 --host 127.0.0.1 --port 4176 --strictPort`

이 주소는 해당 PC의 로컬 서버가 실행 중일 때 접속할 수 있다. PC나 개발 세션 종료로 서버가 멈추면 다시 실행해야 한다. 브라우저에 저장된 화면 일부가 남아 있다고 서버가 실행 중인 것은 아니다. 기록 삭제로 해결할 문제로 안내하지 않는다.

이번 작업에서는 전체 오프라인 교실 검사를 다시 실행하지 않았다. 실제 태블릿·물리 키보드·외부 배포 호스트 검증은 기존 인수 조건을 유지한다.
