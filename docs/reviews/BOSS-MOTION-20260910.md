# 최종 보스·한글 공격·보행 수정

사용자가 확인한 문제: 보스의 같은 문장 반복, 타격 반응 부족, 한국어 모드의 캐릭터 공격 이미지에 영문 키가 보임, 걷기·타이핑·펫 동작의 어색함.

## 반영

- 한국어·영어 각각 최종 문장12개. 갑옷·코어·마무리 역할별4개에서 하나씩 선택한다. 같은 판 안의 중복과 직전 판의 같은 세트를 피하고, 건너뛰어 실제 입력한 세트도 반복 방지에 반영한다. 오답은 현재 목표를 유지해 직접 고치도록 한다.
- 결정 후보10개, 러시 한국어26개·영어24개. 큐 중복과 최근 출제를 피하며, 목표가 하나뿐일 때 건너뛰기가 횟수만 소모하지 않게 했다. 변형 도전에도 보스 역할과 관계없는 편지·전보 문장이 섞이지 않는다.
- 입력한 글자가 캐릭터에서 목표까지 날아가며, 부분 정답은 작은 충돌, 완성 정답은 큰 충돌·넉백·실제 피해 숫자로 구분한다. 작은 공격은 HP나 점수를 중복 획득하지 않는다. 마지막 한 문장까지 정확한 완성이 필요하다.
- 보호막 단계 HUD는 보스 HP 대신 남은 결정 수를 보여 준다. 결정 균열·파괴, 갑옷 분리, 코어 점등과3개 인장이 전투 진도를 보여 준다. 타이핑·게임 타이머를 멈추는 전역 hit-stop은 사용하지 않는다.
- 한국어4캐릭터의 공격 이미지를 가·나·다 시트로 교체했다. 캐릭터4명·펫4종의 좌우 보행 시트도 생성했다. 영어 공격과 앞/뒤 이동은 기존 시트를 사용한다. 생성·프롬프트·패킹 경로는 `../media/motion-v2.md`에 기록했다.
- 프레임별 접지 원점·몸 높이를 기존 idle 크기에 맞추고, 펫 스킬/응원 뒤 이동 유지, 공격 후 원래 자세 복귀, 중복 피격 tween 정리와 장면 종료 후 콜백 차단을 보완했다.
- OS 동작 줄이기에서는 비행·넉백·기울기·카메라 흔들기를 줄이고 정답·피해·페이즈 정보는 유지한다.

## 검증과 한계

코어9묶음 규칙검사와 타입검사는 PASS. 실제 한영 콘텐츠에서 역할별 정답 완주, 큐·skip·오답 우회 차단, 같은 세트 회피, 실제 피해 합계를 확인했다. 변형 도전의 재도전·연습 왕복 인수도 보존한다.

최종 버전은 **0.3.2**, 로컬 미리보기는 `http://127.0.0.1:4176/?v=0.3.2`다. Windows에서 이전 출력 폴더 정리가 거부되어 `npm run build -- --outDir dist-release-v032`로 새 출력 경로를 사용했다. 최종 TypeScript 검사·Vite/PWA 빌드 모두 PASS. 배포에 사용할 폴더는 `dist-release-v032/`다.

자동화 검사는 전투 반응과 연결의 증거이며, 학생의 재미·재도전 의사를 측정한 점수는 아니다. 개별 최종 문장은 다음 판에 다시 나올 수 있지만 직전 판과 같은 전체 세트는 피한다. 실제 Windows 한글 IME, 교실 다기기, 최종 호스팅 성능과 이번 빌드의 전체 오프라인 완주는 이번 범위에서 미실시다.
