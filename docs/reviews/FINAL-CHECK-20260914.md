# 타이핑 어드벤처 v0.5.0 — 반응형 개선 최종점검

검수일: 2026-09-14 KST. 아래 내용은 `npm run build`로 만든 로컬 `dist/`의 배포 전 검수다. 이후 사용자 승인으로 같은 산출물을 GitHub와 Vercel production에 반영했다. 공개 주소 검증은 [배포 완료 기록](DEPLOY-20260914.md)에 별도로 남겼다. 사용자 요청에 따라 랭킹 기능은 추가하지 않았다.

**판정: 조건부 배포 가능.** 확인한 화면 겹침·클릭 방해·입력 조작 결함은 수정 후 통과했다. 실제 교실 기기 검수와 기존 미디어 이용권 증빙은 별도 인수 조건이다.

**200/231점, 21/21항목 검토.** 각 항목은 10점에서 시작하고 WARNING/NOT TESTED당 1점을 감점했다. 이번 검수에서는 11점을 부여하지 않았다. 검수 범위와 미확인 항목을 새로 명시했으므로 과거 보고서와 점수 차이를 그대로 품질 변화로 해석하지 않는다.

- `npm run check`, `npm run check:gameplay`, 타입 검사, 최신 `npm run build` 통과.
- 전투 브라우저 6/6 + 한영 커서/IME 이벤트/낱말 이동 3/3 통과.

- 엔딩 10/10: 실제 영상, 재생 생명주기, 오류 대체·인증서 흐름.

## 남은 인수 조건

1. **실제 기기:** 전자칠판 뒷자리, iPad/Android의 가로·세로/설치 PWA, 화면 키보드·외부 키보드 한글 IME, 학교 와이파이 동시접속을 확인한다. 자동 크기 변화 검사는 기기 실측을 대체하지 않는다.
2. **학생 반응:** 타자 경험이 다른 학생으로 혼자 시작하기, 도움 이해, 피로·재도전 의사, 오답 이유 설명과 새 문장 적용을 관찰한다. 계획은 `docs/delivery/CLASSROOM-PILOT.md`에 있다.
3. **기존 미디어 증빙:** `assets/CREDITS.md`와 `docs/delivery/HANDOFF.md`에 이미 미확인으로 기록된 Suno 음악/Higgsfield 영상의 생성 당시 이용권과 납품 범위를 확인한다. 이번에 새 미디어를 만들거나 이용권을 승인한 것은 아니다.
4. **운영:** 업데이트 후 수업 준비를 다시 확인한다. 구버전 자료 캐시의 장기 누적 관리는 별도 보완 사항이며, 실제 최종 배포 주소에서는 업데이트·오프라인 재접속을 한 번 더 확인한다.
