# 팝업과 캐릭터 표시 통합 검증

2026-09-11. 사용자 요청에 따라 전체 팝업의 크기·여백·투명도를 정리하던 중 추가로 제보된 캐릭터 이름과 공격 언어 오류를 함께 수정했다. 기존 이미지 파일을 재사용했으며 이번 변경으로 새 이미지나 영상을 생성하지 않았다.

## 표시 변경

- `popups.css`는 패널 재질에만 투명도를 적용한다. 일반 창은 남색 86%, 종이 창은 94%, 배경 덮개는 24%다. 텍스트·버튼 자체는 투명하게 만들지 않는다. 영상용 전체 화면 덮개는 이 규칙에서 제외한다.
- Setup은 고정 높이와 내용 영역의 늘어남을 제거했다. 난이도는 3개 비교 카드로 정리하고, 짧은 화면의 소개 상자는 캐릭터·펫 위쪽에 둔다.
- Intro는 미션을 짧게 보여 주고 별 조건·타자 팁·도움 모드는 별도 내용 페이지로 연다. 필수 연습을 마치기 전에는 연습 버튼을, 마친 후에는 전투 버튼을 보여 준다. 연습 허가 로직은 그대로다.
- Result는 결과/성장/선물 탭을 유지하면서 현재 페이지에 맞는 자연 높이로 줄였다. 카드 전체가 들어가는 만큼 페이지를 구성하며 왼쪽 캐릭터 영역을 가리지 않는다.
- 설정·가이드·이야기·도감·인증서·연습·모험 플러스 등은 짧은 페이지로 모든 내용에 접근할 수 있다. 페이지 끝의 비활성 버튼으로 초점이 빠지는 문제도 수정했다.
- 이름 24자와 예전 저장 형식의 자기평가 80자도 자르지 않는다. 전체 문장은 직접 쓰기 쪽에서 읽고, 별도 문장 고르기 쪽에서는 선택 상태를 표시한다.

## 캐릭터 오류

Setup/도감이 기존 `profile.name`을 유지한 채 `characterId`만 바꾸던 것이 이름 불일치 원인이었다. 자동 캐릭터 이름은 현재 캐릭터를 따라가며, 다른 개인 별명은 번역하거나 바꾸지 않는다. 한영 진행·코인·별·학습 기록은 보존된다.

현재 소스에서 정상 자료가 준비된 보라의 한국어 공격은 원래 한글 atlas를 사용했다. 제보 당시 외부 브라우저의 정확한 파일/로딩 상태까지 재현했다고 주장하지 않는다. 감사에서 확정된 한국어 자료 누락 시 영어 그림 대체 경로와 영어 지호의 한글 이펙트를 수정했으며, 손상·누락·복구·언어 전환까지 검증했다.

## 전달 산출물과 한계

최종 로컬 폴더: `dist-preview-20260911-character-sync/`. manifest `60fd41175bd2dd15`, 429자산·53,089,062B. 모든 manifest 항목의 SHA-256·크기와 4176 응답을 검사했다. 미리보기는 `http://127.0.0.1:4176/?v=0.3.3-character-sync`다. 커밋·원격 배포는 수행하지 않았다.

해상도 검사는 가로 게임 화면 기준이다. 실제 초등학생 대상 재미·이해도 실험, 모든 캐릭터로 모든 스테이지를 처음부터 끝까지 완료하는 전수 플레이, 실제 수업용 오프라인 전체 자료 다운로드를 했다는 의미는 아니다. 개별 범위의 세부 한계는 각 검증 문서에 명시했다.
