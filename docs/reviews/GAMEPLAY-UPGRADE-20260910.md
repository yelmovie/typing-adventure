# 플레이 재미 개선 — 2026-09-10

사용자 체감 평가 140/210을 이번 개선의 출발점으로 삼는다. 220/210은 지향점이며, 구현이나 자동 검사만으로 재미·교육 효과에 그 점수를 부여하지 않는다.

## 단계와 완료 기준

1. **짧고 실감 나는 추격전**: 스테이지 2 거리 1000→500m, 보통 제한 시간 180→90초, 목표 시간 110→55초. 실력별 시간·붙잡힘을 이전과 비교한다. 몬스터가 계속 보이고, 멈춤·오타 때 가까워지고 정확한 입력 때 거리를 벌릴 수 있어야 한다. 무입력 클리어는 허용하지 않는다. 이전 1000m 고스트를 새 기록과 비교하지 않는다.
2. **자연스러운 동행**: 실제 atlas의 연속 보행 프레임으로 달린다. 타격마다 큰 점프나 크기 변화가 겹치지 않는다. 펫의 응원·기술 이후에도 달리기가 이어진다. 일반·동작 줄이기 환경을 확인한다.
3. **보스 전체가 보이는 화면**: 1스테이지 대장과 최종 보스 첫 페이즈를 공격 프레임까지 확인한다. 몸·결정이 화면과 입력 패널에 잘리지 않게 배치한다.
4. **입력하고 싶은 낱말**: 한국어·영어 모두 짧은 소리·간식·장비·탐험 소재를 쓰고, 문장 단계에는 이어지는 작은 이야기를 넣는다. 기존 학습 난도와 저장 ID를 보존한다.
5. **직접 해보는 연습실**: 홈에서 언제든 열고 새 모험에서는 지도 전에 안내한다. 입력, 오타 고치기, 띄어쓰기·문장부호, 연속 성공을 직접 통과한다. 실패·시간 압박 없이 반복하며, 연습 완료는 언어별로 저장한다. 모험 점수·코인·학습 실적을 가짜로 늘리지 않는다.
6. **합쳐서 검증**: 규칙 검사, 실제 브라우저의 한·영 튜토리얼, 추격·동행·보스 경계, 작은 화면, 최종 빌드와 주요 회귀 검사를 수행한다. 실제 아동의 재도전 의사와 학습 전이는 별도 사용자 검증으로 남긴다.
