# 품질 근거 감사 — v0.3.2 기준 및 v0.3.3 후속 검사

이 문서는 21항목 재채점에 사용할 기존 증거의 시점과 미검증 범위를 정리한다. 점수를 새로 부여하지 않는다. 처음 수행한 v0.3.2 감사는 읽기 전용이며 새 전체 검사·제품 빌드·제품 소스 수정 없이 작성했다. 그 이후 승인된 v0.3.3 실제 흐름 검사는 문서 끝의 별도 절에 기록한다. 최종 빌드의 판정은 루트 담당자의 통합 결과를 따른다.

## 판정 기준

- **현재 근거**: v0.3.2의 해당 변경 또는 최종 이미지·메타데이터를 직접 검증한 기록.
- **이전 근거**: v0.3.0/v0.3.1에서 확인한 동작. 동일 코드의 회귀 근거로 참고하되, 이후 변경된 전체 앱이나 새 배포본의 검증으로 확대하지 않는다.
- **NT**: 수행하지 않은 검사 또는 현재 자료로 확인할 수 없는 항목. 계획·구현·테스트 개수만으로 해소하지 않는다.
- 자동 입력과 시뮬레이션은 판정·연결·시간 규칙의 증거다. 학생의 실제 속도·학습 전이·재미·재도전 의사와 구분한다. 디자인의 조형·세계관·그림체 평가는 렌더링 오류나 픽셀 크기 측정과 별도의 판단이다.
