# v0.3.3 디자인 검수 결과

최종 소스: HomeScreen, WorldMapScreen, IntroScreen, ResultScreen, StageIntroScene 위치 배치 및 journey.css. 최종 지도 보완은 하단 빛 패널 높이 조정과 상단 핀 안전영역 제한이다. 지역 좌표·Phaser 도달 위치는 유지하고, 번역된 라벨 높이가 커질 때만 노드 묶음이 화면 위로 넘어가지 않게 보정했다. 4·5번 지역은 작은 화면에서 폭을 확보해 영어 단어가 중간에서 끊기지 않는다. 새 이미지 생성, 저장 구조 변경, 게임 판정 변경은 이 디자인 작업에 포함하지 않았다.

## 점수

| 평가 범위 | 현재 /10 | 판단 근거 |
|---|---:|---|
| 화면 균형 | 9.0 | 홈의 주행동 집중, 소개의 목표·회복 보상 우선, 결과의 정확도·완성 수·점수 첫 화면 노출 |

| 홈 | 8.9 | 이어하기 1개를 우선하고 튜토리얼·모험 플러스 2개를 보조로 유지, 나머지는 명시적 펼치기 안에 배치 |
| 지도 | 9.0 | 4/5개 빛 회복과 다음 목적지를 함께 표시. 하단 상태 문구 겹침과 상단 4·5번 핀 잘림을 해소하고, 현재 핀 움직임·hover까지 전체 표시를 확인 |
| 소개 | 9.0 | 실제 미션→되찾을 빛→행동 순서로 정리. 상세 목표·난이도·별 조건과 키보드 팁은 접기. 캐릭터·펫을 축소하지 않고 패널 밖 안전 위치로 이동 |
| 결과 | 9.1 | 되찾은 빛과 핵심 3성과가 먼저 보이고, 학습 기록·실제 점수 공식·보상은 접기. 다음 지역 이동은 항상 접근 가능 |

초기 시각 진단 종합 7.6/10에서 화면 균형 9.0/10으로 개선했다. 이 숫자는 화면에 대한 전문가 판단이며, 초등학생의 재미나 교육 효과를 실측한 점수가 아니다. 12/10을 검증 점수로 주장하지 않는다.

## 실제 검수

- 1920×1080, 1280×800, 1024×768, 915×412 × KO/EN × 홈·지도·소개·결과: **32/32 PASS**.
- Enter로 홈/소개/결과 상세 접기·펼치기, 숨겨진 메뉴 접근, 결과 상세 기록 스크롤 후 주버튼 접근: **8/8 흐름 PASS**.
- 1280/915 × KO/EN 소개: **4/4 PASS**. 플레이어·펫의 전체 sprite bounds는 패널 밖, 보스 bounds는 화면 안전 영역 안. 영어 대사 표시는 250ms 간격 18회 샘플에서 한글 접두어 노출 0.
- 915 EN reduced-motion 소개: **1/1 PASS**. 영어 대사 완성 문자열만 표시, 한글 혼합 0.
- 마지막 지도 CSS 보완 후 1024 KO/EN: **2/2 PASS**. 패널 높이 143.07px→99.87px, 첫 지역 보조 문구와 약 9px 간격. 각 빛의 이름은 aria-label/title 유지.
- 상단 지도 핀 최종 추가 회귀: **8/8 PASS**. 4해상도 × KO/EN에서 회전된 핀·라벨·별·상태문구 전체 bounds가 게임 영역 안에 있음을 확인했다. 1.4초 현재 핀 움직임 샘플과 4·5번 hover 상태도 포함했으며 제목·상단바·지역 라벨 간 겹침은 없었다.
- 결과 별은 점등 애니메이션 완료를 기다린 최종 915·1920 KO 샷에서 실제 3개를 확인했다. 초기 일부 샷의 두 별 모양은 점등 중 프레임이다.
- TypeScript 검사와 소유 소스 diff whitespace 검사 PASS. 제품 빌드는 root 담당.

## 한 번 발생한 대기 시간 초과

1920 EN 초기 전체 실행 중 새 S4 페이지로 이동한 뒤 battle 준비 대기에서 60초 초과가 1회 있었다. 당시 화면은 빈 남색 캔버스였고 pageerror는 0이었다. 같은 홈→지도→소개→S4 실제 입력 완료→결과 흐름을 단독 재실행한 결과 PASS였으며, 요청 실패·HTTP 오류·콘솔 오류·pageerror 모두 0이었다. 원인은 확정하지 못했다. 여러 브라우저의 동시 GPU/CPU 부하는 가능성일 뿐 확인된 원인으로 적지 않았다.

## 남은 한계

- 실제 학생을 대상으로 '지금 할 일/얻을 보상' 회상, 접힌 메뉴 발견, 5~8분 지속 흥미를 측정하지 않았다.
- 실제 태블릿 터치·보조공학 기기와 교실 하드웨어는 미검증이다. 브라우저 viewport 및 키보드/포인터 검사와 구분한다.
- 작은 지도에서는 빛 이름 대신 표식과 개수를 우선한다. 이름은 접근성 설명·마우스 설명과 각 지역 소개/결과에서 확인할 수 있다.
