# 왼손·오른손 자판 안내 — v0.4.0

연습 튜토리얼과 전투 자판 가이드에 같은 손 구분 규칙을 적용했다.

- 왼손 키: 파랑, 키 왼쪽 안쪽 선
- 오른손 키: 분홍, 키 오른쪽 안쪽 선
- Space: 보라, `양손 엄지` 안내
- 각 자판 위에 `왼손 / 오른손 / 양손 엄지` 범례 표시
- 손의 경계가 시작되는 키 앞에 간격과 점선을 추가해 색을 구분하기 어려워도 영역을 알 수 있게 함
- 쌍자음·영문 대문자는 글자 키 반대편 Shift를 다음 키로 안내
- Delete·Enter는 오른손, 좌우 Shift는 각각 해당 손으로 표시

검증 결과:

- 한글 전투와 영문 전투 자판의 손 매핑·범례·반대편 Shift 안내 통과
- 튜토리얼 한글 1280×720, 한글 915×412, 영문 1280×720에서 가로·세로 넘침 없음
- 기존 IME 입력, 미완료 이탈 방지, 연습 완료 후 전투 이동, 새로고침·언어별 기록 검사가 모두 통과
