## 이번 개선의 실행 증거

- `npm run build`, `npm run check`, `npm run check:gameplay` 통과.
- 정식 빌드의 Opening 8/8 통과: 첫 프레임 전 Phaser 미요청, 실제 재생·정지·자연 종료·작은 화면·autoplay 거절·영상 실패·런타임 실패·영문 포커스.
- 전투 브라우저 흐름 5/5, 핵심 로직과 한영 콘텐츠 검사 전체 통과.
- 팝업 한글 1280×800의 15종 93상태, 영문 915×412의 15종 108상태 통과. 화면 밖 넘침과 불필요한 세로 스크롤 없음.
- 공개 한글 온라인과 영문 완전 오프라인에서 각각 5지역 3별 완주. 준비 입력 3/3/1/2/0, 본게임 실제 정답 20/31/6/3/18.
- 공개 manifest 418개/53,021,799B 모두 HTTP 200·SHA-256 일치. OG 1번 JPG 252,863B, canonical/OG/Twitter 절대 주소, 저장 후 브라우저 뒤로가기 복원, production debug hook 없음.
- 배포 제외 배경 12개는 공개 산출물에서 404, 유지 배경은 200. 제작 원본 24개는 빌드 전후 바이트 동일.

## 성능 해석

런타임을 인트로 첫 프레임 뒤로 옮겨 진입 JS를 11.20KB로 줄였다. 첫 프레임 시점의 게임 런타임·Phaser·BGM 요청은 3회 모두 0건이고 서비스워커도 아직 등록되지 않았다. 첫 화면 전송 용량은 이전 약 5.866MB에서 이번 2.125~4.227MB로 기준을 통과했다.

첫 프레임은 3회 중 2회가 1.4초 이내였지만 첫 회 3.213초가 있어 3초 기준을 통과했다고 단정하지 않는다. 첫 조작 버튼은 세 번 모두 1.686초 이내였다. CDP 수신량은 브라우저가 받은 인코딩 바이트이며 학교 라우터 전체 오버헤드와 같은 값은 아니다.

## 남아 있는 인수 조건

- Suno 음악과 Higgsfield 영상의 **생성 당시 상업 이용 가능 플랜 증빙**이 필요하다. 출처 기록만으로 상업 이용권을 추정하지 않는다.
- 수준이 다른 학생 6~8명으로 재미·피로·도움 없이 시작·오답 이유 설명·새 사례 적용·며칠 뒤 유지 효과를 관찰한다.
- 실제 물리 키보드 IME, 전자칠판 뒷자리, 학교 와이파이 동시 접속을 교실 환경에서 확인한다.
- 제한망 첫 영상 프레임이 3회 모두 3초 안에 드는지 다른 시간대와 학교 회선에서 반복 측정한다.

남은 조건은 코드를 더 복잡하게 만들어 대신할 수 없는 현장·권리 증거다. 브라우저 자동 입력을 학생 학습 효과로 바꾸거나, 확인되지 않은 이용권을 통과로 표시하지 않았다.
