## 확인된 문제

### F-1. 스테이지 1 을 초보자가 클리어할 수 없다 — `FAIL(확인됨)` · A 영역

1. **문제** 목표 사용자(초등 타자 초보)의 입력 속도로는 첫 스테이지에서 30초 안에 HP 가 0 이 된다.
2. **우선순위** P1 — 상당수 학생이 첫 화면에서 막힌다. A 영역이라 예외 불가.
3. **발생 화면** 스테이지 1 「푸른 숲」 전투 (wave 모드)
4. **재현 절차** `node tmp/balance.mjs` — 낱말 하나를 N초마다 정답 입력하는 봇으로 자동 재현.
5. **예상 결과** 초등학생 속도(낱말당 5~8초)로도 첫 스테이지는 클리어된다.
6. **실제 결과**

   | 입력 속도 | 표준 난이도 | 기초(도움) 난이도 |
   |---|---|---|
   | 무입력 | **20.7초 만에 사망** | — |
   | 8초/낱말 (느린 초보) | **25.9초 사망** (2낱말) | **35.1초 사망** (3낱말) |
   | 5초/낱말 | — | **94.8초 사망** (6낱말) |
   | 4초/낱말 | **28.8초 사망** (5낱말) | — |
   | 3초/낱말 | — | 클리어 (49.3초, 12낱말) |
   | 1.5초/낱말 | 클리어 (97.6초, 최저 HP 100 — **한 대도 안 맞음**) | — |

   빠르면 **한 대도 안 맞고**, 조금만 느리면 **30초 만에 죽는다.** 중간이 없다.

7. **확인 근거** 위 표는 전부 실제 브라우저 실행 결과다. 수치의 출처는 `WaveSystem.ts`:
   - 등장 간격 `intervalStart 2.2초 → intervalEnd 1.1초` (WaveSystem.ts:39-40)
   - 슬라임 이동 `travelSec 9초`, 박쥐 `6.5초` (WaveSystem.ts:42)
   - 접촉 피해 `touchHp 10`, 접촉 후 제거가 아니라 `pushBackTo 0.25` 로 되밀림 (WaveSystem.ts:43-44)

   즉 **2.2초에 한 마리씩 처치해야 줄이 밀리지 않는다.** 2음절 낱말 기준 대략 150타/분 이상이라야 유지되는 속도다. 교실 언어로: **손가락으로 자판을 짚어 가며 치는 아이는 첫 판에서 한 마리도 못 잡고 죽는다.**

   기초 난이도(`DIFFICULTY_RULES.beginner`, stages.ts:146)는 `timeMul 1.35` 로 **적 이동만 74% 로 늦출 뿐 등장 간격은 그대로**라(WaveSystem.ts:122) 처리량 요구가 바뀌지 않는다. 그래서 위 표에서 기초 난이도도 5초/낱말에 죽는다.

8. **관련 파일** `src/game/systems/WaveSystem.ts:35-65`, `src/game/data/stages.ts:132-150`, `src/game/systems/TypingRun.ts:17-47`
9. **권장 수정** 8장 「재미 강화 설계」의 1~3번(속도 적응형 스폰·접촉 처리 변경·도움 모드 자동 제안)
10. **수정 위험** 밸런스 상수 변경은 `scripts/check-wave.ts` 가 잡는 범위 밖이다. 수정 후 `tmp/balance.mjs` 를 다시 돌려 표를 새로 채워야 한다.
11. **검증 방법** 위 표에서 **8초/낱말이 클리어**로 바뀌고, 1.5초/낱말도 여전히 클리어면 통과.
12. **증거등급** `확인됨`

### F-2. 느린 회선에서 홈 화면까지 40초 — `FAIL(확인됨)` · D 영역

- 실측(production preview, Playwright + CDP 스로틀 1.5Mbps/300ms):

  | 회선 | FCP | 홈 버튼 조작 가능까지 |
  |---|---|---|
  | 빠른 회선 | 108ms | **1.26초** |
  | 느린 4G(1.5Mbps) | 1,660ms | **39.8초** |

- 홈 화면 하나 띄우는 데 **7.3MB / 72요청**. 그중 **스프라이트 4.67MB** 가 캐릭터 4종·펫 4종 시트 전부다.

  ```
   638 KB  sprites/char_blond_explorer.webp
   609 KB  sprites/pet_squirrel.webp
   579 KB  sprites/char_pink_girl.webp
   576 KB  sprites/char_brown_boy.webp
   545 KB  sprites/char_glasses_boy.webp
   531 KB  sprites/pet_dragon.webp
   450 KB  sprites/pet_cat.webp
   437 KB  sprites/pet_rabbit.webp
  ```

  실제로 쓰는 건 **선택한 캐릭터 1 + 펫 1 = 약 1MB** 다. 나머지 3.6MB 는 셋업 화면 미리보기용으로만 필요하다.
- 학교 공유 Wi-Fi 에서 30명이 동시에 접속하면 이 값이 그대로 체감된다.
- 관련: `docs/PLAN.md` 12장의 "캐릭터·펫 시트 선택분만 로딩" 이 바로 이 항목이다.
- **증거등급** `확인됨`

### F-3. 카카오톡·검색 미리보기가 안 나온다 — `FAIL(확인됨)` · G 영역

- `index.html` 에 `og:image`·`og:title`·`twitter:card` 가 **하나도 없다**(meta 4개: charset·viewport·theme-color·description).
- `<link rel="icon">` 도 없고 `public/favicon.ico` 도 없다. PWA manifest 에는 아이콘이 있지만 브라우저 탭 파비콘은 별개다.
- 교사끼리 링크를 카톡으로 주고받는 게 이 프로젝트의 주 배포 경로인데, 지금 링크를 붙이면 **회색 빈 카드**가 뜬다.
- **증거등급** `확인됨` (파일 내용 직접 확인)

### W-1. 미사용 OG 샘플 18.6MB 가 배포에 포함된다 — `WARNING(확인됨)` · D·G 영역

- `public/assets/og/og-sample-01~05.png` 5장, 각 3.7MB. `dist` 총 56MB 중 **18.6MB(33%)**.
- 어디서도 참조되지 않는다(`og:image` 자체가 없으므로). `.vercelignore` 는 소스 `assets/` 만 막고 `public/` 은 안 막아서 그대로 배포된다.
- PWA precache(84항목 2.5MB)에는 안 들어가므로 로딩 속도에는 영향 없다. **용량과 배포 시간에만 영향.**

### W-2. 인증서 모달 상단이 잘린다 — `WARNING(확인됨)` · C 영역

- 1920×1080 과 915×412 에서 닫기(✕) 버튼 박스가 `y −8 ~ 58` — 위로 8px 잘린다.
- 915×412(폰 가로)에서는 제목 칩 「오늘의 인증서」까지 잘려 글자 위쪽이 날아간다. 스크린샷 `tmp/qa-shots/phone-915-modal-cert.png`.
- 버튼 자체는 지름 50px 이상이 남아 **누를 수는 있다.** 그래서 FAIL 이 아니라 WARNING.

### W-3. Phaser 층이 `prefers-reduced-motion` 을 무시한다 — `WARNING(확인됨)` · C 영역

- CSS 는 잘 대응돼 있다 — `src/styles/animations.css:128` 에 20개 넘는 선택자를 끄는 블록이 있다.
- 그런데 **TS 어디에도 `prefers-reduced-motion` 이나 `matchMedia` 가 없다.** reduced-motion 컨텍스트로 홈 화면을 열었을 때 Phaser 트윈 3개가 그대로 돌았다.
- `settings.screenShake` 는 별도 수동 설정이라 이걸 대신하지 못한다.

### W-4. 학습 콘텐츠에 힌트·오개념 피드백이 없다 — `WARNING(확인됨)` · A 영역

- `content.json` 174개 유닛 중 **`hint` 필드를 가진 것 0개**. UI 에는 `bb-hint` 자리가 있는데(`HudController.ts:139`) 지금은 "다음 낱말: ○○" 예고에만 쓰인다(`HudController.ts:171`).
- 오답을 냈을 때 **무엇이 틀렸는지**(받침이 빠졌는지, 이중모음을 잘못 눌렀는지) 알려주는 데이터가 없다. 점수만 깎인다.
- 난이도 분포도 초보에게 불리하다: **난이도 1 이 16개**, 난이도 2 가 110개, 난이도 3 이 48개. 첫 스테이지에서 만나는 낱말 대부분이 받침·이중모음이 든 난이도 2 다.

### W-5. 도움 모드가 3번 죽은 뒤에야 나온다 — `WARNING(확인됨)` · A 영역

- `IntroScreen.ts:73` — `fails >= 3 || assist` 일 때만 도움 모드 버튼이 보인다.
- F-1 과 겹치면 이렇게 된다: 초보가 첫 판에서 30초 만에 죽고, 두 번째도 죽고, 세 번째도 죽은 **다음에야** "도움 모드를 켜 볼래?" 가 뜬다. 그때쯤 아이는 이미 창을 닫았다.

- 목표 낱말이 몬스터 머리 위와 하단 패널에 동시에 크게 표시된다. 눈이 두 군데를 오간다.

같은 세션에서 F-1 을 고치고 **똑같은 `node tmp/balance.mjs` 로 다시 쟀다.**

**A7 난이도: `FAIL` → `PASS(확인됨)`.** 초보 속도로 첫 스테이지가 클리어된다. 가만히 있으면 여전히 진다.
