# 캐릭터 동작·추격·보스 경계 검수 — 2026-09-10

## 변경과 원인

- 원본 캐릭터 4종·펫 4종 atlas를 비교했다. `run_right`는 연속 동작 프레임이 아니라 큰 도약/잔상이 들어간 단일 자세다. 이를 `walk_0 → run → walk_2 → run`으로 섞던 배열을 4개 보행 자세의 12fps 연속 주기로 바꿨다. 속도에 따라 0.75~1.35배 재생한다.
- Player와 Pet는 각자 UPDATE 시계 하나로 그리는 위치만 조금 들어 올린다. 씬이 관리하는 실제 x/y 좌표와 외부 이동 tween을 덮어쓰지 않는다. 몸을 가로·세로로 반복 늘이던 변형을 제거했다.
- 연속 이동 중 글자 성공·피격·응원은 달리기를 중단하지 않는다. 펫은 정답 응원/스킬 이후에도 원래 walk/run 동작을 유지한다. 중복 jab, hop, nudge에는 중복 방지가 있고, 방향키 점프/앉기와 전투 콜백은 유지했다.
- S2 추격자는 실제 `gap`을 X 위치에, `threat`를 크기와 가까운 영역의 색에, `chaserSpeed`를 다리 주기에 연결했다. 1280px 화면의 맨 왼쪽으로 밀려나 보이지 않던 배치를 변경했다. 상시 섬광은 없고, 터보는 작은 국소 효과만 사용한다.
- S5는 idle 그림보다 공격 그림이 훨씬 높다(visible paint 208px / 265px). 2.5배에서 최대 2.0배로 맞춰 공격 때 머리 위 키까지 HUD 아래에 넣었다. 결정 5개의 아크/글자 위치를 다시 배치했다. 915×412에서 상단 HUD에 가려지던 결정 낱말이 보인다.
- S1 대장 슬라임은 기존 1.3125배에서 공격 프레임까지 안전 영역에 들어와 별도의 WaveScene 변경이 필요하지 않았다.
- OS 동작 줄이기에서는 몸 들림, 레이스 배경 이동, 파티클/국소 플래시, 카메라 흔들림을 중지한다. 실제 추격 거리 이동과 다리 프레임은 게임 진행을 전달한다.
