# 재도전·영어 준비 연습 회귀 검증 · 2026-09-12

## 오늘의 도전 재도전

코드 리뷰에서 오늘의 문장/긴 글을 완료한 뒤 `바로 다시 도전`을 누르면 `dailyKind`가 누락되어 기본 낱말 모드로 바뀌는 결함을 확인했다. `ResultScreen`이 daily 재도전에 `currentDailyKind()`를 전달하도록 수정된 source에서 실제 입력으로 검증했다.

| 언어 | 선택한 종류 | 실제 완료한 문항 | 재도전 결과 |
|---|---|---:|---|
| 한국어 | 낱말 | 20 | 낱말 유지 |
| 한국어 | 문장 | 10 | 문장 유지 |
| 한국어 | 긴 글 | 10 | 긴 글 유지 |
| 영어 | 낱말 | 20 | 낱말 유지 |
| 영어 | 문장 | 10 | 문장 유지 |
| 영어 | 긴 글 | 12 | 긴 글 유지 |

6/6 PASS. 총 82개를 실제 DOM 입력칸에 입력해 완료했다. 성공 결과 화면에서 재도전 버튼을 클릭한 뒤 종류, 전체 문항 수, 당일 첫 목표가 동일하고 새 실행의 완료 수가 0인지 검사했다. 이어 첫 문제를 다시 입력해 정상 진행도 확인했다. 완료 기록은 각 언어에서 `2026-09-12`, `2026-09-12:sentence`, `2026-09-12:long`에 구분되어 저장됐다. 런타임 오류는 0이었다.

- 하네스: `scripts/check-daily-retry.mjs`
- 실행: `DAILY_RETRY_URL=http://127.0.0.1:5181`, `DAILY_RETRY_OUT=tmp/daily-retry-final-20260912`
- 증거: `tmp/daily-retry-final-20260912/results.json` 및 `ko/en-word/sentence/long-retry.png`
- 독립 임시 프로필·브라우저 한 개에서 순차 진행했다. 실제 사용자 저장은 사용하지 않았다.

첫 시도는 source 서버가 JS/CSS를 전달하지 못해 기본 HTML에서 탐색 timeout으로 끝났다. 서버 재시작 뒤 위 여섯 흐름이 모두 통과했다. 첫 실패는 게임 실행에 도달하지 않은 개발 서버 문제로 구분했다.

## 영어 준비 연습

요청한 `scripts/check-tutorial-flow.mjs`를 `TUTORIAL_LANGUAGE=en`, `TUTORIAL_TEST_URL=http://127.0.0.1:5181`로 실행했다. 1280×720에서 종료 코드 0으로 완료했다.

- 기본 모음 5개 전체 연습을 자유 연습에서 계속 선택할 수 있다.
- 지역 1~4의 최초 준비가 3/3/1/2문제로 끝난다.
- IME 조합 중 Enter로 완료가 먼저 처리되지 않는다.
- 틀린 채 나가면 준비 완료로 기록되지 않으며, 전투 직접 접근도 준비로 돌아간다.
- 준비 완료 후 다음 버튼은 바로 전투로 이동한다.
- 다시 들어온 지역은 준비를 반복하지 않고, 보스는 네 완료 파트를 재사용한다.
- 새로고침 뒤 준비 완료가 유지된다.
- 다른 언어에는 완료가 새어 나가지 않고, 원래 언어로 돌아오면 완료가 복원된다.

증거는 `tmp/tutorial-en-final-20260912/results.json`, 최신 `tmp/tutorial-parts/en-1280-stage_1/2/3/4-complete.png`와 실행의 최종 PASS 출력이다. JSON에는 네 지역의 준비 문항 수가 기록되며, 위 수명주기·언어 격리 항목은 스크립트 assertion으로 확인했다. 이전 결과 JSON은 `tmp/tutorial-parts-before-en-20260912.json`에 보관했다.

두 검사 모두 브라우저 정상 종료를 확인했다. 이번 문서는 source의 실제 기능 회귀 증거이며, 최종 원격 배포 점검이나 실제 학생의 난이도 평가를 대신하지 않는다.
