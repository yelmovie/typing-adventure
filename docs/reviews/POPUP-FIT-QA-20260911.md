# 팝업 내용 맞춤 검증

2026-09-11. 소스 개발 서버 `http://127.0.0.1:5180`을 Chrome·Playwright의 격리 컨텍스트로 검사했다. 사용자 브라우저의 탭·저장 기록은 조작하지 않았다. 구현은 다른 작업자가 맡았고, 이 문서는 `scripts/check-popup-fit.mjs` 및 관련 저장 회귀의 독립 검증 기록이다.

## 범위와 결과

한국어·영어 × 1280×800, 1024×768, 915×412, 1920×1080 × 아래 15종으로 **120개 기본 케이스, 764개 화면 상태**를 검사했다. 최종 합산 결과는 **120/120 통과**다. 본문과 페이지·패널·문서의 불필요한 스크롤, 화면 밖 텍스트, 잘린 버튼, 클릭을 가리는 요소는 없었다. 측정된 최소 버튼 크기는 가로·세로 각각 47.995px(렌더링 오차를 포함한 48px), 문서 넘침은 0px였다.

| 팝업 | 실제 검사 범위 |
|---|---|
| 설정 | 소리·화면, 도움말, 연습·다시보기, 기록 관리 4쪽 및 전체 초기화 확인창 |
| 학생 가이드 / 교사용 가이드 | 각각 16쪽 / 14쪽의 모든 본문 |
| 시작 이야기 / 끝 이야기 | 각각 7장면 / 4장면, 이전·다음 버튼 |
| 제작 정보 | 3쪽 전체 |
| 모험 도감 | 몬스터·배지·친구·아이템·칭호의 전체 페이지; 크기별 2/4/6개 카드 |
| 인증서 | 인증서, 도전 기록, 오늘 기록, 학습 기록, 문장 고르기, 직접 쓰기; 선택·저장 동작 |
| 연습 | 오답, 세 문제, 완료 화면 |
| 모험 플러스 | 지역·목표·보상 6쪽 |
| 수업 준비 | 준비 전·준비 완료의 안내 길이 |
| 오늘의 도전 | 세 가지 도전 선택 |
| 일반 안내 / 삭제 확인 | 본문과 버튼, 삭제 확인의 기본 취소 선택 |
| 소리 설정 | 작은 팝오버, Escape 후 원래 버튼 초점 |

모든 모달에서 배경의 `inert`, 마지막 페이지에서도 유지되는 초점, Tab·Shift+Tab 순환, Escape 닫기와 원래 버튼으로 초점 복원을 확인했다. 삭제 확인은 최초 Enter가 기록 보존을 선택한다. 페이지의 모든 본문은 실제 이전·다음 버튼으로 도달했다. 화면 크기에 따라 의도적으로 숨긴 중복 제목은 필수 노출 본문에서 제외했다.

## 수정 과정에서 확인한 결함

- 짧은 화면의 음량 백분율 줄바꿈, 설정 도움말 버튼 영역의 세로 넘침.
- 인증서의 기존 2열 통계 규칙 충돌, 본문과 페이지 버튼 겹침, 자기평가 내용 과밀.
- 마지막 쪽에서 다음 버튼이 비활성화되면 키보드 초점이 배경으로 빠지는 문제.
- 영어 교사 가이드·친구 카드·긴 연습 문장 간격으로 생긴 작은 넘침.

각 담당자가 레이아웃·페이지 구성을 고친 뒤 해당 케이스를 재검증했다. 내용을 잘라 숨겨서 맞추는 방법은 사용하지 않았다.

첫 전체 실행은 116/120이었다. 인증서 4건은 실제 결함이 아니라 (1) 짧은 화면에서 숨긴 중복 제목과 (2) 자연 높이 본문 마지막 글자의 2px 잉크 확장을 하네스가 잘못 셌다. 하네스를 고친 후 인증서 8개를 재검증해 모두 통과했다. 실제 페이지·스택·본문·패널 경계 및 텍스트 Range 잘림 검사는 계속 적용한다. 합산 근거는 `tmp/popup-fit-final/verified-results.json`이며, 원 실행과 재검증 파일 출처를 함께 기록했다.

## 추가 경계와 저장 회귀

- 이름 24자 + 자기평가 24자를 저장한 한국어 인증서: 1920×1080에서 전체 6쪽을 연 뒤, 창을 유지한 채 915×412로 줄이고 다시 모든 쪽을 이동했다. **13상태 통과**, 이름·자기평가 값도 그대로였다. 근거: `tmp/popup-fit-boundary-24/results.json`.
- 오래된 저장 스키마의 자기평가 80자에서는 실제 넘침을 찾아 담당자에게 전달했다. 5쪽에서 긴 문장을 6쪽 직접 쓰기 영역으로 옮기고 줄바꿈·간격을 보완했다. 이름 24자 + 자기평가 80자로 다시 1920×1080 전체 6쪽 → 창이 열린 상태에서 915×412 변경 → 전체 6쪽을 검사해 **13상태 최종 통과**했다. 이름과 80자 문장도 그대로 보존된다. 근거: `tmp/popup-fit-boundary-80-final/results.json`.
- 위 인증서 재구성 후 영어 915×412 인증서의 6쪽 및 선택·저장 **7상태 통과**. 근거: `tmp/popup-fit-en-cert-final/results.json`.
- 설정 전체 초기화: **1/1 통과**. 취소 시 원문 보존, 명시적으로 모두 지운 뒤에는 양쪽 언어 기록이 초기화된다. 근거: `tmp/popup-save-reset-regression/results-recheck.json`.
- 도감의 새 친구 장착: **1/1 통과**. 진행 보존, 홈 즉시 표시, 다시 접속한 후에도 장착 상태 유지. 근거: `tmp/popup-save-equip-regression/results-recheck.json`.
- 도감 이미지 디코딩을 기다리도록 촬영을 보강한 뒤 915×412 한국어 전체 탭 **31상태 재검증 통과**. 그림이 비어 보인 초기 촬영은 로딩 전 촬영 문제였다. 근거: `tmp/popup-fit-collection-images/results.json`.

짧은 한국어·영어 설정, 도감, 교사용 가이드, 인증서, 긴 이름 인증서의 스크린샷을 직접 검토했다. 배경이 창 밖과 반투명 소재 뒤로 보이고 본문과 버튼은 읽을 수 있다. 투명도 전체를 낮추는 방식이 아니라 패널 소재에만 투명도가 적용된다.

## 필수 연습 버튼 회귀

필수 연습 전 비활성 전투 버튼을 빼고, 연습 완료 후 전투 버튼을 표시하도록 정리한 최종 변경도 따로 검사했다. `TUTORIAL_LANGUAGE='en' node scripts/check-tutorial-flow.mjs`를 같은 소스 서버의 격리 브라우저에서 실행해 **영어 1280×720, 스테이지 1~5 모두 통과**했다(종료 코드 0). 스테이지별 21/5/5/4/35개, 총 70개 목표를 실제 입력했다.

- 과거 완료 플래그가 있어도 연습 전에 전투 버튼이 없고 연습 버튼이 보인다.
- 오답 후 중도 이탈로 건너뛸 수 없으며 직접 전투 진입 요청도 필수 연습으로 이어진다.
- 연습을 끝내면 전투 버튼이 나타나 실제 전투로 진입한다. 한 번 사용한 연습 허가는 소비되어 다시 연습이 필요하다.
- IME 조합 중 Enter는 제출되지 않고, 키 누름·해제 표시가 정상이다. 브라우저 예외는 없다.

하네스의 추가 수정은 필요하지 않았다. 새 완료 화면 근거는 `tmp/tutorial-parts/en-1280-stage_1-complete.png`부터 `en-1280-stage_5-complete.png`까지다. 이 추가 실행은 영어 1280 한 크기만 다뤘다.

## 한계와 재실행

이 검사는 소스 서버의 UI 검증이다. 최종 production 빌드, 사용자 기존 탭의 서비스 워커 상태, 초등학생 대상 실제 이해도·재미 테스트는 별도다. 수업 준비 완료 화면은 격리 CacheStorage의 합성 파일 2개로 상태 문구만 검증했으며 실제 오프라인 자료 다운로드나 오프라인 준비 성공을 뜻하지 않는다. 시작 안내·설정 화면·결과 화면·파이널 영상은 다른 담당자의 독립 검사 범위다.

```powershell
node scripts/check-popup-fit.mjs

$env:POPUP_FIT_FILTER='certificate'
$env:POPUP_FIT_OUT='tmp/popup-fit-certificate-recheck'
node scripts/check-popup-fit.mjs

$env:POPUP_FIT_BOUNDARY='1'
$env:POPUP_FIT_BOUNDARY_CANDO_LENGTH='80'
$env:POPUP_FIT_OUT='tmp/popup-fit-boundary-recheck'
node scripts/check-popup-fit.mjs
```

필터를 바꿀 때 이전 `POPUP_FIT_BOUNDARY`, `POPUP_FIT_VIEWPORT`, `POPUP_FIT_LANGUAGE` 환경 변수도 비워 준다.
