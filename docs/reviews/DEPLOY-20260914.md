## 배포 방식

최종 검수한 `dist/`를 Vercel Build Output API의 `.vercel/output/static/`에 복사하고 모든 manifest 항목의 바이트·SHA를 다시 확인했다. `config.json`은 version 3 정적 산출물 설정을 사용했다. `vercel deploy --prebuilt --prod --yes`로 해당 파일을 그대로 올렸으며 Vercel에서 다른 빌드를 다시 만들지 않았다. 원본 이미지·작업 자료·인증 파일을 공개 정적 파일에 포함하지 않았다.
