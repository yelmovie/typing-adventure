# 팝업 모듈 분리 검증 — v0.4.0

## 변경

`ModalController.ts`의 공개 함수 17개는 그대로 유지하고, 팝업의 역할에 따라 `src/game/ui/modals/` 아래 8개 모듈로 나눴다. 기존 호출부는 같은 진입점을 계속 사용하므로 화면 전환 계약과 저장 계약은 바뀌지 않는다.

- 공통 수명주기·초점·배경 처리: `ModalHost.ts`
- 알림·확인·언어 시작 안내: `BasicModals.ts`
- 설정·도움말·도감·기록: 각 전용 모듈
- 프롤로그·엔딩·인증서·재도전·연습: `AdventureModals.ts`, `RecordModals.ts`
- 교실 시작 도우미: `ClassroomModal.ts`

## 검증

- TypeScript 검사 통과
- 한글 1280×800: 팝업 종류 15개, 상태 93개가 화면 안에 맞고 의도하지 않은 세로 스크롤 없음
- 영문 915×412: 팝업 종류 15개, 상태 108개가 화면 안에 맞고 의도하지 않은 세로 스크롤 없음
- 도감은 16/31개 상태, 인증서는 7개 상태, 연습은 실제 오답 비교·이유 선택·새 예시 입력까지 검사
- 브라우저 `pageerror` 0건

증거는 `tmp/popup-modules-v040-ko1280-v2`와 `tmp/popup-modules-v040-en915`에 보존한다. 작은 화면의 기기 브라우저 주소창·실물 키보드 동작은 별도 현장 점검 범위다.
