작성일: 2026-09-21 (KST)

## 현재 판정

**로컬 릴리스 후보 통과.** 빌드, 핵심 게임 규칙, 연습 화면, 전투 입력, 반응형 레이아웃, 오프라인 교실 배포 패키지 검사가 모두 통과했다. 실제 공개 주소의 최종 검사는 이번 커밋을 배포한 뒤 한 번 더 실행해야 한다.

로컬 확인 주소: <http://127.0.0.1:5180/>

## 이번에 완료한 작업

- 스테이지 1에서 화면에 보이는 낱말을 순서와 관계없이 입력해 해당 몬스터를 공격하도록 변경
- 왕슬라임을 10시 방향에서 등장시키고 기존 왕슬라임 표현의 2배 크기로 표시
- 왕슬라임은 낱말을 5번 완성해야 처치되며, 1~4타에는 남은 타격 수를 표시
- 콤보 소탕·펫 광역 공격으로 왕슬라임이 즉사하지 않도록 보호
- 코인·점수 보상을 전투 하단에 항상 보이게 표시
- 사용 아이템 7종 인벤토리 추가
  - 하트: HP 20 회복
  - 별: 점수 150점
  - 방패: 다음 접촉 1회 방어
  - 번개: 적 3초 감속
  - 초록/파랑/보라 보석: 적 2/4/6초 완전 정지
- 아이템은 하단 왼쪽에 모이고, 슬롯 선택 후 `F1` 또는 화면의 `F1 사용` 버튼으로 사용
- 아이템 획득·사용 상태를 저장하고 체크포인트와 동기화
- 학생 가이드에 아이템 종류와 사용법 추가, 영어 번역 추가
- 연습 화면의 회색 손 그림과 노래방식 자모 색칠 제거
- 장문 연습은 위 원문을 보고 아래 입력란에 따라 쓰는 방식으로 복원
- 초기 로딩에서 선택 영상·전체 효과음을 미리 받지 않도록 최적화
- OG 이미지 1200×600 v3 적용
- AI Mart 썸네일 1024×1024 제작
  - 상단 실제 `타이핑 어드벤처` 로고
  - 좌측 하단 `실과`, `국어` 배지
  - 파일: `public/icons/ai-mart-thumbnail.jpg`
- 사용하지 않는 구형 OG와 손 그림 파일을 배포 대상에서 제거

## 집에서 이어서 할 일

### 1. 배포 후 공개 주소 검사 — 필수

배포가 끝난 뒤 새 공개 주소와 로컬 `dist`가 같은지 확인한다.

```powershell
$env:HOSTED_URL='https://실제-배포-주소/'
node scripts/check-hosted-release.mjs
```

통과 조건: 공개 OG v3, PWA manifest, classroom manifest 421개 자산과 해시, 저장 복원, 외부 요청 없음.

### 2. 실제 키보드 수동 확인 — 권장

- 스테이지 1에서 하트나 보석 슬롯 선택 → `F1` 한 번 → 수량 1 감소와 효과 확인
- `F1`을 길게 눌러도 한 번만 사용되는지 확인
- 보석 정지 중 다른 보석을 눌렀을 때 소모되지 않는지 확인
- HP가 가득 찼을 때 하트가 소모되지 않는지 확인
- 왕슬라임이 1~4타에 버티고 5타에만 쓰러지는지 확인

### 3. AI Mart 등록 — 수동 작업

- 썸네일: `public/icons/ai-mart-thumbnail.jpg`
- 콘텐츠 간략소개: 한글 낱말과 문장을 입력해 몬스터를 물리치고 여러 지역을 모험하는 타자 학습 RPG로, 정확도와 타수를 높이며 올바른 키보드 사용 능력을 기른다.
- 연관 과목: 실과·국어
- 연관 단원명/차시명: 실과 5~6학년 「디지털 기기와 콘텐츠 활용」 / 국어 「글자와 단어를 바르게 쓰기·문장과 문장 부호를 알맞게 쓰기」

## 나중에 다듬을 수 있는 비차단 항목

1. 왕슬라임 1~4타 진행은 전투 중 새로고침하면 5타부터 다시 시작한다. 화면 몬스터를 저장하지 않는 현재 체크포인트 설계 때문이며, 일반 플레이·배포를 막는 문제는 아니다.
2. `F1`은 브라우저·학교 기기 정책에 따라 도움말 키로 가로챌 수 있으므로 화면의 `F1 사용` 버튼을 항상 함께 제공한다. 실제 납품 기기에서 한 번 확인한다.
3. AI Mart 썸네일은 앱 실행 자산이 아니므로 교실 오프라인 패키지와 PWA 초기 캐시에서 제외했다. 업로드용 원본만 프로젝트에 보관한다.
