# 납품 전 UI 고도화 · 구현 및 실측 기록

작성: 2026-09-10. 디자인 및 final-check 스킬을 적용했다. 기존 픽셀 배경, 캐릭터, 폰트, 보상 자산을 유지했으며 신규 이미지나 프레임워크를 추가하지 않았다.

## 화면 구성

- Phaser 1920×1080 좌표를 유지하면서 실제 화면 배율을 CSS에 전달한다. 주요 본문은 최소 16px, 주요 조작 글자는 18px, 버튼은 48px 실제 높이를 기준으로 한다. 작은 화면에서 카드와 문장을 무조건 축소하지 않고 역할별 그리드 및 본문 스크롤을 사용한다.
- 홈은 이어하기를 주 행동으로 두고 모험가·친구 변경을 독립 기능으로 제공한다. 진행 기록을 유지하는 설정 변경과 현재 언어의 새 모험을 구분한다. 한국어/English 선택, 모험 플러스 진입을 연결했다.
- 영문 홈에는 CSS로 금빛 TYPING / ADVENTURE 로고를 표시한다. 한국어 로고는 기존 이미지 자산을 사용한다.
- 설정을 모험가 → 난이도 → 친구의 세 단계로 나누었다. 카드에 native button, aria-pressed, 상태 설명을 제공하고 탭의 방향키 이동을 지원한다. 완료할 때 키보드 가이드 설정을 초기화하지 않는다.
- 지도의 잠김/현재/완료 상태를 글자로도 구별한다. 5번 지역과 겹치던 도구 모음을 왼쪽 위로 옮겼다. 화면 전환 중에는 UI를 inert 상태로 두고 전환/로딩 실패 후 입력을 복구한다.
- 결과 화면의 잘못된 가로 넘침을 제거하고 숫자 카드, 성장 안내, 액션 영역을 구분한다. 결과의 학습 내용 자체와 배치는 학습 기능 담당 변경과 통합한다.
- 이야기 모달의 고정된 큰 빈 공간을 없애고 본문만 스크롤한다. 설정, 도감, 인증서, 소리 설정에도 글자 및 조작 크기 기준을 적용했다.
- 전투 상단은 지역/진행/시간을 우선하고 작은 화면에서는 보조 통계를 줄인다. 입력창과 점프/키보드 가이드 버튼 크기를 확보했다.
- 편지는 종이, 현재 문장, 복원한 문장, 세 봉인으로 구성했다. 배경의 기존 문을 가리던 큰 단색 도형을 제거했다. 열차의 두꺼운 판을 얇은 금속 패널로 바꾸고 빠른 전체 화면 점멸을 완만한 효과로 교체했다.
- 편지·열차의 영어 표시를 추가하고 웨이브·달리기·보스·오늘의 도전의 Canvas UI 문구를 번역 함수에 연결했다. 영어 모험의 장식 글자와 도장도 영어로 표시한다.
- OS의 동작 줄이기 설정에서 공통 배경 줌·주변 반짝이·홈 환호·지도의 자동 이동·결과 색종이를 줄이고 공격 이펙트를 작은 정적 표시로 대체한다. 웨이브/달리기의 배경 이동 및 장식 반복, 보스 보석·코어 진동, 카메라 흔들림을 중단한다. 웨이브의 큰 섬광과 카메라 줌은 짧은 고정 안내로 바꾸되 몬스터 진행과 게임 판정은 유지한다. 게임의 화면 흔들림 옵션 의미는 바꾸지 않았다.

## 실제 브라우저 확인

CUA로 개발 서버 화면을 열고 스크린샷 및 DOM의 렌더링 크기를 확인했다. 아래 수치는 CSS 원본 크기가 아닌 화면 배율이 반영된 측정이다.

| 화면/크기 | 확인 결과 |
|---|---|
| 설정 · 1024×768 | 카드 이름 18px, 설명 16px, 카드 네 개의 가로 넘침 0. 이전/다음 버튼 실제 높이 48px. 본문 clientWidth=scrollWidth. |
| 설정 · 915×412 | 패널 하단 400.56px로 화면 안에 위치. 본문 가로 넘침 0, 세로 스크롤 사용. 이전/다음 버튼 48px. |
| 설정 · 1280×800, 1920×1080 | 실제 스크린샷에서 카드·미리보기 겹침 없이 표시. 기존 픽셀 방과 캐릭터 유지. |
| 키보드 카드 선택 | Enter로 보라, Space로 지호 선택 후 aria-pressed와 미리보기가 함께 갱신되는 것을 확인. |
| 친구 변경 | 도감과 지역 기록이 있는 상태에서 토끼를 선택하고 완료. 기존 지역 클리어/별/레벨을 유지한 상태로 지도와 홈에 반영. |

| 영문 설정 · 1024×768 | 영어 모험가 카드 네 개 및 세 단계 탭, 설명, 다음 버튼이 잘림 없이 표시됨. 복합 이름의 번역 잔여분은 번역 담당에 전달. |

## 검증 범위

이 문서는 UI 담당의 직접 확인 범위다. 마지막 통합 빌드, 전체 전투 회귀, 오프라인 및 모든 영어 코퍼스의 검사는 별도 통합 검수 결과를 따른다. 실제 학생 사용성, 학습 전이, 학교 장비의 물리 키보드/IME, 스크린리더의 전체 동선은 아직 현장 검증하지 않았으므로 만점이나 검증 완료로 계산하지 않는다.
