# 전투 화면 모듈 분리 검증 — v0.4.0

## 변경

`BattleScreen.ts`에서 도전 방식 생성, 한영 문구, 판정 연출을 분리했다. 여섯 도전 방식의 생성은 `createBattleMode.ts`, 화면 문구는 `BattleCopy.ts`, 타격·판정·타이머 정리는 `BattleFeedback.ts`가 맡는다. 화면 클래스는 입력과 수명주기 연결에 집중한다.

## 검증

- TypeScript 검사 통과
- 핵심 로직 검사 전체 통과: 일반 전투, 레이스, 편지, 열차, 보스, 오늘의 도전, 학습 기록, 보상, 진행도, 전체 여정
- 브라우저 전투 흐름 5/5 통과
  - 새 목표가 나타날 때까지 입력과 시간이 함께 멈춤
  - 열차 오답·Tab 우회로 허위 완료 불가, 실제 정답만 저장
  - Escape·설정·탭 숨김에서 일시정지하고 사용자가 눌러야 재개
  - 오늘의 도전 수정 입력이 성장 기록에 반영
  - 영문 문장 대소문자 교정, Shift 자판 안내, 완료 저장
- 브라우저 `pageerror` 0건

증거는 `tmp/battle-flow-check`에 보존한다. 실제 학생이 느끼는 타격감과 피로도는 교실 관찰 전까지 확인되지 않은 항목으로 유지한다.
