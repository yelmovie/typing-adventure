## 빌드와 검사

```powershell
npm ci
npm run typecheck
npm run check
npm run check:gameplay
npm run build
npm run preview -- --host 127.0.0.1 --port 4180 --strictPort
```

브라우저 검사는 각 스크립트의 URL 환경 변수를 실제 서버와 맞춘다. `check:tutorial`은 개발 서버에서, `scripts/check-release-journey.mjs`는 production에서 수행한다. 테스트용 프로필만 사용하며 기존 브라우저의 기록은 초기화하지 않는다.

배포에는 dist/ 안의 정적 자산만 필요하다. 원본 assets/, 작업 출력 output/, 개발 tmp/는 공개 사이트가 아니다. 로컬 .vercel/ 및 인증 설정은 Git에 넣지 않는다.

## 업데이트와 기록

과거 코드로 열려 있어 업데이트 알림 자체가 없는 경우, 이 게임의 기존 탭을 모두 닫고 다시 연다. 구버전에는 대기 중인 새 서비스워커를 적용하는 버튼이 없어서 새로고침만으로는 전환되지 않을 수 있다. 브라우저 전체 데이터 삭제는 필요하지 않다. 새 버전부터는 홈이나 지도에 나타나는 새 버전 열기 버튼으로 적용할 수 있다.

기록은 URL의 출처(origin)와 브라우저 프로필별로 남는다. localhost에서 배포 도메인으로 이동한다고 기록이 자동 복사되지는 않는다. 언어 전환은 각 언어 기록을 보존하며, 새 모험 시작은 선택한 언어만 다시 시작한다.

## 교실 준비

온라인 상태에서 설정의 수업 자료 준비를 완료하고, 전체 개수와 준비 상태를 확인한다. 같은 브라우저에서 오프라인으로 지역·영상·인증서를 확인한다. 업데이트 후 자료 준비를 다시 검사한다. 공용 기기는 학생별 브라우저 프로필을 분리한다.

## 인수 전 남은 확인

**Suno 음악과 Higgsfield 영상의 생성 당시 상업 이용 가능 플랜은 사용자가 2026-09-12에 ‘확인이 필요해’라고 답했다.** 출처 기록은 있지만 유료 납품 이용권 증빙은 미확인이다. 이 항목을 통과로 표시하지 않는다.

실제 학생의 재미·난이도·학습 전이, 물리 키보드 IME, 교실 뒷자리 가독성, 학교 동시접속은 [수업 파일럿 표](CLASSROOM-PILOT.md)로 별도 관찰한다. 자동 테스트는 아동 관찰이나 성취기준 이수 인증이 아니다.

최종 배포 URL·커밋·검사 결과는 최종 검증 후 이 문서와 최종 점검 보고서에 기록한다.
