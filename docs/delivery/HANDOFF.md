
브라우저 검사는 각 스크립트의 URL 환경 변수를 실제 서버와 맞춘다. `check:tutorial`은 개발 서버에서, `scripts/check-release-journey.mjs`는 production에서 수행한다. 테스트용 프로필만 사용하며 기존 브라우저의 기록은 초기화하지 않는다.

배포에는 dist/ 안의 정적 자산만 필요하다. 원본 assets/, 작업 출력 output/, 개발 tmp/는 공개 사이트가 아니다. 로컬 .vercel/ 및 인증 설정은 Git에 넣지 않는다.

## 업데이트와 기록

과거 코드로 열려 있어 업데이트 알림 자체가 없는 경우, 이 게임의 기존 탭을 모두 닫고 다시 연다. 구버전에는 대기 중인 새 서비스워커를 적용하는 버튼이 없어서 새로고침만으로는 전환되지 않을 수 있다. 브라우저 전체 데이터 삭제는 필요하지 않다. 새 버전부터는 홈이나 지도에 나타나는 새 버전 열기 버튼으로 적용할 수 있다.

기록은 URL의 출처(origin)와 브라우저 프로필별로 남는다. localhost에서 배포 도메인으로 이동한다고 기록이 자동 복사되지는 않는다. 언어 전환은 각 언어 기록을 보존하며, 새 모험 시작은 선택한 언어만 다시 시작한다.
