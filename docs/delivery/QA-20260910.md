준비 완료 뒤 CSS 글꼴 요청이 다른 `Origin` 헤더를 사용하면서 기존 `Vary: Origin` 응답을 다시 받아 검증 표시가 풀리던 오류를 재현하고 수정했다. SHA 검증한 동일 출처 정적 파일의 저장 응답에서 `Vary`를 제거하며, 캐시는 배포 버전별로 구분한다.
