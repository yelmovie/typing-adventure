# 수업 적용·실사용 검수표

대상 버전: 0.4.0 · 계획 갱신: 2026-09-12

이 문서는 시행할 수업과 관찰 방법이다. 아래의 학생·교사 검증은 아직 수행하지 않았다. 게임 점수와 자동화 테스트를 실제 교육 효과나 재미의 증거로 대체하지 않는다.

## 40분 수업 예시

| 시간 | 활동 | 교사가 볼 수행 |
|---|---|---|
| 0~5분 | 홈에서 한국어/English 선택, 자판·Enter·수정·휴식 익히기 | 혼자 목표를 읽고 입력·수정·일시정지할 수 있는가 |
| 5~25분 | 수준에 맞는 지역과 도움 난이도 선택 | 정확히 완성한 입력, 첫 오류, 고친 입력을 구분하는가 |
| 25~30분 | 결과의 교정 연습 3개 | 실제 오답과 목표의 차이를 고른 뒤 원래 오류 1개를 고치고 다른 예시 2개에 같은 규칙을 적용하는가 |
| 30~35분 | 게임 밖에서 자신의 한 문장 쓰기 | 한국어는 띄어쓰기와 마침표, 영어는 대문자 시작·공백·마침표를 스스로 확인하는가 |
| 35~40분 | 결과·인증서 살펴보고 다음 목표 정하기 | 빠른 속도와 높은 정확도의 차이, 도움 친구를 고른 이유를 설명하는가 |

독립 쓰기 예시: 한국어는 오늘 고마웠던 일을 한 문장으로 쓴다. 영어는 알고 있는 단어로 자신이 좋아하는 것을 한 문장으로 쓴다. 완성 문장을 먼저 보여 주지 않고 학생이 내용을 정한 뒤, 교사가 학생 수준에 맞게 피드백한다. 앱은 이 활동의 정오나 국어·영어 성취도를 자동 판정하지 않는다.

## 언어·지역별 활동 대응

| 활동 | 한국어 연습 | 영어 연습 | 현재 앱에 남는 기록 |
|---|---|---|---|
| 숲·도시 | 낱말 자모·받침·모음 | 영문 자판·짧고 긴 단어 | 실제 입력, 오류, 정확도, 활동 시간 |
| 편지 | 띄어쓰기·문장부호 | 문장 첫 대문자·공백·마침표 | 고친 문장과 다른 예시의 성공 |
| 열차 | 정확하게 전달하기 | 문장 순서대로 정확하게 입력하기 | 완성한 전보와 제동 진행 |
| 성채 | 낱말·문장 종합 | 단어·문장 종합 | 단계별 성공과 완주 |
| 오늘의 도전·모험 플러스 | 다른 낱말에 적용 | 다른 단어·문장에 적용 | 개인 기록·세 가지 수행 목표·누적 인장 |

이 표는 활동의 내용 대응이다. 공식 성취기준 인증표가 아니다. 담당 교사는 학교에서 사용하는 교육과정의 성취기준 원문, 학년, 단원, 해당 문항을 대조하여 별도 승인한다. 영어는 단어 뜻·문법·말하기 전체를 가르치는 과정으로 소개하지 않는다.

## 실제 아동 관찰

가능하면 타자 경험이 다른 학생 6~8명으로 먼저 관찰한다. 로그인이나 이름을 추가 수집하지 않고 교사가 익명 번호로 메모한다.

- 첫 목표를 혼자 시작하는 데 걸리는 시간과 도움을 요청한 지점.
- 오답을 고쳐 성공했는지, 새로운 예시에서도 같은 규칙을 적용했는지.
- 완주 후 선택: 새 조합 도전·친구 바꾸기·휴식 중 무엇을 원하는지와 이유.
- “왜 이 인장을 받았어?”, “이 친구는 무엇을 도와줬어?”에 대한 설명.
- 피로, 시간 압박, 글씨 읽기 어려움, 소리·움직임 불편.
- 며칠 뒤 같은 난이도의 다른 예시를 제시했을 때 정확도와 수정 방식. 이미 외운 문장만 반복한 결과와 구분.

목표는 오래 붙잡아 두는 것이 아니라 학생이 자기 성장을 이해하고 다시 연습할 이유를 찾는 것이다. 쉬는 날에도 인장을 잃지 않으며 교사는 수업 종료와 휴식을 자유롭게 안내할 수 있다.

## 실제 장비·납품 주소 확인

- [ ] 학교 태블릿 + 실제 외부 키보드: 한글 조합·받침·영문 Shift·문장부호·연속 입력.
- [ ] 화면 회전, 브라우저 확대, 블루투스 키보드 끊김·재연결 후 입력 복구.
- [ ] 전자칠판 뒷자리에서 목표와 버튼 식별, 스피커 소리 켜기·끄기·볼륨.
- [ ] 수업 준비 다운로드 완료 → 네트워크 차단 → 미방문 지역 포함 다섯 지역 완주·결과 저장·인증서.
- [ ] 여러 기기에서 동시에 최초 다운로드할 때 회선·저장 공간과 준비 시간.
- [ ] 최종 주소에서 새로 접속·재방문·서비스워커 갱신·영상·메타 이미지 확인.
- [ ] 생성 당시 Suno/Higgsfield 플랜 및 상업 이용 범위 증빙 첨부.

이 체크를 실제로 수행한 날짜·장비·결과를 납품 검수표에 기록한다. 주소나 브라우저가 바뀌면 기존 localStorage 기록이 자동 이전되지 않는다.
