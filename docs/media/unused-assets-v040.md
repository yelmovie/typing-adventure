# 미사용 배경의 납품 제외 기록 — v0.4.0

## 원칙

제작 원본은 삭제하거나 바꾸지 않는다. `scripts/delivery-exclusions.json` 한 곳에서 납품 제외 목록을 관리하고, Vite 빌드가 만든 복사본과 오프라인 manifest에서만 제외한다.

## 결과

- 런타임에서 참조하지 않는 `_blur.webp` 배경 12개, 112,622바이트를 산출물에서 제외
- 선택되지 않은 OG 후보 폴더와 이전 파이널 포스터도 기존 기준대로 산출물에서 제외
- 실제 사용하는 `bg_main_gate_blur.webp`는 유지
- 최신 정식 산출물 manifest: 418개, 53,021,799바이트
- 남은 418개 파일의 크기·SHA-256 일치
- 제외 배경 12개는 HTTP 404, 유지 배경은 HTTP 200
- `public/`의 배경과 제작용 `assets/background/` 원본 24개는 빌드 전후 바이트가 동일

자동 검사는 새 `_blur` 참조가 생기면 실패시켜 사람이 제외 목록을 다시 검토하도록 한다. 증거는 `tmp/asset-audit-v040-final`에 보존한다.
