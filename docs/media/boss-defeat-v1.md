## 프레임

3열 × 2행, 왼쪽에서 오른쪽 순서다.

1. 마지막 타격과 첫 균열
2. 무릎이 꺾이며 몸이 낮아짐
3. 코어 과부하
4. 장갑·키캡 파편 분리
5. 금빛·보랏빛 사각 파편으로 분해
6. 잔해와 빛이 사라지는 정착 프레임

## 최종 프롬프트 요약

기존 키보드 골렘의 얼굴, 남색 석재 장갑, 금빛 균열, 왕관 문양, 키보드 키 장식과 아동 친화적 판타지 톤을 유지한다. 정확히 6개의 연속 사망 프레임을 3×2로 배치하고, 동일 카메라·크기·발 기준선을 사용한다. 투명 배경이며 UI, 설명문, 프레임 번호, 워터마크, 유혈, 공포 표현, 다른 캐릭터와 부엉이 소재는 넣지 않는다.
